# Автоматический парсер цен и аналитика (FastAPI + PostgreSQL + Excel)

Веб-сервис для регулярного мониторинга цен на товары, отслеживания динамики на интерактивных графиках и выгрузки аналитических отчетов в Excel. Включает встроенный демо-магазин для безопасного тестирования парсинга в реальном времени.

## Основной функционал

### Аналитика и визуализация (Публичный режим)
* **Интерактивные графики:** визуализация истории изменения цены выбранного товара с линией целевой цены на базе `Chart.js`.
* **Умная индикация:** автоматический расчет отклонения от желаемой цены и подсветка выгодных предложений.
* **Демо-стенд:** встроенные страницы товаров (`/demo-store/laptop`, `/demo-store/phone`) с динамической генерацией цен для демонстрации работы системы без риска блокировок от внешних площадок.

### Управление и автоматизация (Режим администратора)
* **Фоновый мониторинг:** планировщик `APScheduler` автоматически опрашивает все отслеживаемые ссылки по заданному расписанию и сохраняет историю в PostgreSQL.
* **Гибкий парсинг:** извлечение цен через `httpx` и `BeautifulSoup4` как по точному CSS-селектору, так и через автопоиск по микроразметке и мета-тегам.
* **Экспорт в Excel (`.xlsx`):** генерация оформленного отчета через `openpyxl` с двумя листами (сводка текущих цен с отклонениями и полная история замеров).

## Безопасность и архитектура

* **JWT-авторизация:** доступ к добавлению, обновлению, удалению товаров и выгрузке Excel-отчетов защищен токенами (`HS256`, время жизни 8 часов).
* **Защита от SSRF-атак:** строгая валидация входящих URL с проверкой схемы и блокировкой приватных сетевых диапазонов (включая проверку после HTTP-редиректов).
* **Rate Limiting и защита от XSS:** ограничение частоты запросов на вход и ручной парсинг с одного IP, а также безопасный рендеринг DOM-элементов на фронтенде исключительно через `textContent`.

## Технологический стек

* **Backend:** Python 3.11+, FastAPI, SQLAlchemy 2.x, Pydantic v2, APScheduler, httpx, BeautifulSoup4, openpyxl, PyJWT, bcrypt
* **База данных:** PostgreSQL
* **Frontend:** Vanilla JavaScript (Fetch API), HTML5, Tailwind CSS, Chart.js

## Быстрый запуск локально

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   git clone https://github.com
   cd Price-Parser-Analytics
   ```

2. **Создайте виртуальное окружение и установите зависимости:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Настройте переменные окружения:**
   Скопируйте `.env.example` в `.env` и укажите ваши параметры:
   ```env
   DATABASE_URL=postgresql+psycopg2://postgres:password@localhost:5432/price_tracker_db
   CHECK_INTERVAL_MINUTES=30
   SECRET_KEY=ваш_секретный_ключ_jwt
   ADMIN_PASSWORD=admin123
   ```

4. **Запустите сервер:**
   ```bash
   uvicorn app.main:app --reload
   ```
   * Дашборд: `http://127.0.0`
   * Документация API: `http://127.0.0docs`
